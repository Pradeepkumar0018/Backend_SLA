3. What is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic. With JavaScript, we can make buttons work, change text, show messages, calculate values, validate forms and create many other actions on a webpage.JavaScript is like the brain of a website. HTML creates the structure of the website and CSS makes it look good, while JavaScript makes the website work and respond when the user does something.
